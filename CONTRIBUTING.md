# Contributing

## Running the tests

```bash
pip install "ooxml-common @ git+https://github.com/uvrt/ooxml-common@main"   # or -e ../ooxml-common
pip install -e '.[dev]'
pip install -e packages/pptx2svg-fonts
pytest              # serial, as CI runs it; pytest -n auto to use every core
```

More in [docs/development.md](docs/development.md): the snapshot tests in `tests/vrt/`,
and the generated tables that must be regenerated by their tool, never edited by hand.

## Local-only tests

The fidelity harness and the tests that score against PowerPoint need PowerPoint's own
PDF exports, the Microsoft faces Office installed and PyMuPDF; they skip on CI and on any
machine without them ([docs/fidelity.md](docs/fidelity.md)). Decks that are not ours to
redistribute live in the gitignored `scratch/`, and the tests that need them skip.

## What never goes into the repository

- Microsoft fonts, or anything derived from them (the font profile is gitignored).
- Office output: PowerPoint's PDF exports, rasters of them, or SVGs converted from them.
- Third-party documents we have no licence to redistribute. Record the provenance of
  every fixture you add in `tests/fixtures/README.md`.

## Pull requests

Open pull requests against `main`. CI must be green on every OS and Python version in the
matrix. Keep constants tied to the measurement that produced them.
