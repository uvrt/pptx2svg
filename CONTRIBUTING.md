# Contributing

## Running the tests

```bash
pip install "ooxml-common @ git+https://github.com/uvrt/ooxml-common@main"   # or -e ../ooxml-common
pip install -e '.[dev]'
pip install -e packages/pptx2svg-fonts
pytest              # serial, as CI runs it; pytest -n auto to use every core
```

More in [docs/development.md](docs/development.md): the snapshot tests in `tests/vrt/`,
and the generated tables that must be regenerated by their tool, never edited by hand.

## Local-only tests

The fidelity harness and the tests that score against PowerPoint need PowerPoint's own
PDF exports, the Microsoft faces Office installed and PyMuPDF; they skip on CI and on any
machine without them ([docs/fidelity.md](docs/fidelity.md)). Decks that are not ours to
redistribute live in the gitignored `scratch/`, and the tests that need them skip.

## What never goes into the repository

- Microsoft fonts, or anything derived from them (the font profile is gitignored).
- Office output: PowerPoint's PDF exports, rasters of them, or SVGs converted from them.
- Third-party documents we have no licence to redistribute. Record the provenance of
  every fixture you add in `tests/fixtures/README.md`.

## Pull requests

Open pull requests against `main`. CI must be green on every OS and Python version in the
matrix. Keep constants tied to the measurement that produced them.

## Names pptx-agent imports

`tests/test_public_api.py` imports every name pptx-agent imports from here, and
[docs/usage.md](docs/usage.md), "Used by pptx-agent", lists the same names, so renaming or
removing one fails this repository's CI instead of pptx-agent's. To rename one, keep the
old name as an alias for one release, with a comment saying who it is kept for, and move
pptx-agent over; a name pptx-agent starts importing is added to both. pptx-agent imports
no name that starts with an underscore: give it a public name first.

## Versions

`pyproject.toml`'s version is the one [CHANGELOG.md](CHANGELOG.md)'s top version section
names, and `pptx2svg.__version__` the same; CI's `build` job checks it
(`tools/check_version.py`). Each version that reaches `main` is tagged `v<version>` on that
commit by the tag workflow (`.github/workflows/tag.yml`), so a sibling's floor on this
package can be checked against a tag. Raise the version with its CHANGELOG section;
changes since the last one go under an `Unreleased` heading above it.

## Dependencies

At runtime pptx2svg needs the standard library and **ooxml-common** alone, which is itself
standard-library only: the format-neutral half of this library (OPC, units, DrawingML's
values, reader and renderers, fonts, the measured text metrics), extracted with its
history so docx2svg can share it (ROADMAP.md, "The shared package"). It is not on PyPI
yet, so it is installed first, from a sibling checkout or from its repository as CI does;
`pyproject.toml` names a version, never a URL, since PyPI refuses a distribution whose
dependencies name one.

- `ooxml-common>=0.27.0`: `drawingml.text_chain`, where a run's inherited colour, size and
  face come from (round 15), which every text body is drawn with. What each earlier
  version added is in ooxml-common's CHANGELOG.

The extras (`png`, `cairo`, `fonts`, `measure`, `metafile`, `fidelity`, `dev`) are
described where `pyproject.toml` lists them.
